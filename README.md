# identity-reference-poc

POC de référence pour une architecture Django Auth + django-allauth Headless + Next.js.

> **Statut : bootstrap IDR-001 en cours.** Ce dépôt ne constitue pas une implémentation de production. Ne pas migrer la base avant la définition du modèle `User` personnalisé (IDR-002).

Voir la branche `chore/idr-001-bootstrap` pour la structure de travail et les contrôles CI. Les décisions seront validées par les gates G0 à G6 de `ROADMAP.md`.
